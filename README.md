# Banana ML — научно-исследовательский прототип

Веб-приложение для **предварительного** прогнозирования измеренных показателей бананов в условиях хранения примерно при 12,8 °C по исходному значению D0.

## Что есть

- В проект включён `data/banana_ml_dataset_v1.csv` — предварительно объединённые экспериментальные данные из опытов V1–V4.
- Графики динамики по всем имеющимся вариантам.
- Отдельные модели Ridge Regression по показателям; для обучения и проверки используются **V1–V3**.
- Прогноз по исходному значению на D0 и горизонту D3, D5, D7, D10.
- Leave-one-variant-out проверка (каждый вариант целиком исключается из обучения), сравнение с постоянным значением D0.
- Выгрузка прогноза и результатов проверки в CSV.

## Чего нет и почему

- Нет доказанного прогноза «физиологического состояния» в классах, степени застуженности или остаточного срока годности: для этого нужны валидированные целевые метки.
- Нет прогноза эффекта газации или температур выше/ниже исследованного режима: подходящих независимых серий недостаточно.
- V4 — другая экспериментальная серия и отображается только на графиках; **V4з в этой сводной CSV-базе не представлен**.
- Нет независимой внешней валидации и интервалов неопределённости. Всего 3 варианта в ML-тесте. Показатели в единицах исходной таблицы — уточнить по первичным протоколам.
- `banana_ml_dataset_v1.csv` — подготовленная первая версия, а **не полный 21-листный исходный Excel**. Нужна отдельная проверка данных и расширение спектральными измерениями.

## Локальный запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## GitHub

Создайте пустой репозиторий и загрузите все файлы с сохранением папки `data/`. В корне должны лежать `app.py`, `ml_core.py`, `requirements.txt`, `render.yaml`.

## Render

1. Подключите GitHub к Render → **New → Web Service**.
2. Выберите репозиторий и Python runtime.
3. Build Command: `pip install -r requirements.txt`.
4. Start Command: `streamlit run app.py --server.address 0.0.0.0 --server.port $PORT --server.headless true`.
5. Разверните приложение. Платформа может изменять тарифы и условия бесплатного использования.

`render.yaml` также задаёт конфигурацию для развёртывания через Render Blueprint (при поддержке выбранного плана).

## Научная оговорка

Модели построены по усреднённым значениям вариант–день, не по независимым плодам. Валидность для новых партий не установлена. Отсутствуют достоверные данные для температурного обобщения и прогноза сроков хранения. Не использовать в качестве единственного основания для решения о приёмке, дозаривании или реализации.
